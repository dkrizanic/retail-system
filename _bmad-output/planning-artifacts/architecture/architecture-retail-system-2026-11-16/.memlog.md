- (decision) AD-1 [ADOPTED]: Pragmatic DDD + Modular Layered Architecture (api -> application -> domain <- infrastructure). Pure Java domain with zero Spring/MongoDB imports.
- (decision) AD-2 [ADOPTED]: Separated Write DTOs (api.dto.write) and Read DTOs (api.dto.read) with polymorphic Price serialization (type: ONE_TIME | RECURRING).
- (decision) AD-3 [ADOPTED]: Interface-driven application services (CartService, StatisticsService) and domain repository ports (ShoppingCartRepository, OfferStatisticsRepository).
- (decision) AD-4 [ADOPTED]: Dual query strategy in infrastructure: Spring Data derived interface methods (findByCustomerIdAndStatus) for simple cart lookups; MongoTemplate/Aggregation pipeline for FR-7 offer and retargeting statistics.
- (decision) AD-5 [ADOPTED]: Single shopping_carts collection with partial unique index on customerId where status=ACTIVE, compound index on items.offerId + items.action + items.addedAt + status, and Decimal128 converters for BigDecimal.
- (decision) AD-6 [ADOPTED]: Zero AI comments in source/test code; unit tests strictly for domain invariants and Testcontainers (@ServiceConnection) integration tests for API and MongoDB flows.
- (version) Verified stack: Java 26 (Temurin 26.0.1), Spring Boot 4.1.2, Maven (mvnw), MongoDB 8.0 LTS / 9.0, Testcontainers.
